## Overview

githMind answers questions about a GitHub repository in plain language: what a
module does, why a file changed, where a behaviour is implemented. You point it
at a repo, it indexes the code and history once, and from then on every answer
cites the files it came from.

## Architecture

A question typed in the browser goes to the Spring Boot API, which embeds it,
retrieves the most similar code and commit chunks from the vector index, builds
a prompt around them, and streams the model's reply back token by token. The
sources arrive after the answer, so the citation list is only ever built from
chunks that were actually in the prompt.
