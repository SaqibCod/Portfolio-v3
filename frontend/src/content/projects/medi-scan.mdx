## Overview

Medi-Scan turns a lab report into something you can actually read. Every value
is explained in ordinary language, with the reference range it is measured
against and a citation back to the source the explanation came from. It runs on
a zero-cost stack, and falls back to a second model automatically when the
primary one is unavailable.

## The problem

A lab report is a table of numbers written for someone who already knows what
they mean. The patient holding it gets a column of values, a reference range in
small print, and no explanation — so the next step is usually a search engine
and an afternoon of worry.

## Architecture

An uploaded report is parsed into individual values, each value is matched
against retrieved reference material in the vector store, and the model is
asked to explain only what it was given. If the primary model fails or times
out, the circuit breaker switches to the local fallback and the response says
which model answered.
