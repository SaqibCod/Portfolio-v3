# Alpha

Alpha is a fixture, not a real project. It exists so the ingestion and retrieval tests have a
knowledge file with known frontmatter and known content to assert on.

Alpha is written in Kotlin and deployed to Fly.io. It indexes recipes and answers questions
about them. The word that only appears here is "artichoke", so a test can prove a chunk came
from this file and nowhere else.
